## Core Cyberduck Features

- **One Bookmark:** Save a host, a protocol, and a user that were given to you. Do not scan for other machines.
- **A Host Key You Check:** The first connection should match the fingerprint the server owner published. A mismatch means you stop.
- **Upload and Download of Your Files:** Move files you are allowed to put there. A shared folder is not a place to browse other people's private trees.
- **Disconnect:** Close the session when the transfer is done. A saved password on a shared PC is a saved login for the next person.

---

## About Cyberduck

Cyberduck is a file transfer client for servers you may use: your own host, or an account someone issued to you. SFTP and similar protocols are the connection. It does not find open servers, and a hostname you guessed is not an invitation. If the login fails, ask the person who runs the host. Do not try passwords.

Check the host key before you trust the session. If it changed and nobody told you it would change, disconnect. Uploading overwrites a remote file with the same name. Download to a folder you chose, not over the only local copy of something else.

A bookmark without a stored password is safer on a computer other people unlock. Type the password when you connect, or use a key you control, and remove the bookmark before you give the PC away.

## Tool Benefits

- **A Named Host:** You connect to one server you can explain.
- **A Checkable Key:** The fingerprint is part of the first login, not an optional detail.
- **A Session You End:** Disconnecting closes the transfer window.

## Getting Started with Cyberduck

Prerequisites: A host, a user, and a fingerprint or a key from the person who runs the server.

1. **New Bookmark:** Enter that host. Do not search the network.
2. **Connect and Read the Key:** Stop if it does not match what you were told.
3. **Transfer One File:** Upload or download something small, then confirm it arrived.
4. **Disconnect:** Remove a stored password if this Windows account is shared.

---

## Professional & Personal Use Cases

- **Your Own Web Host:** Upload a file you built, to a path you were given.
- **A Team Drop:** Use the account the team created, and stay in that directory.
- **A Key Change:** Disconnect and ask before you accept a new fingerprint.
- **A PC You Are Leaving:** Delete the bookmark so the next user does not inherit the login.
